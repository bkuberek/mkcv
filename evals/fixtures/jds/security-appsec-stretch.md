# Staff Application Security Engineer

**Company:** Ironvale Civic Software
**Team:** Product Security
**Location:** Remote (US citizens only, due to federal contract requirements)
**Employment type:** Full time

## About Ironvale Civic Software

Ironvale Civic Software builds case management and benefits eligibility
software for state and federal agencies. Our platform is authorized at FedRAMP
Moderate and we are pursuing FedRAMP High. Our products are written mostly in
Java and Rust, and they run on AWS GovCloud.

## About the role

You will be the senior technical leader of our product security program. You
will find vulnerabilities before attackers do through manual penetration
testing and secure code review, build fuzzing into our Rust services, and
make security tooling part of every pull request. You will also own the
application security controls in our FedRAMP authorization package.

## What you will do

- Perform manual penetration testing of web applications and APIs with Burp Suite
- Lead secure code review for Java and Rust services, focusing on authentication, authorization, and injection flaws
- Build and run fuzzing harnesses for our Rust parsers and file-handling services
- Own static and dynamic analysis in CI, including Semgrep rules and DAST scans
- Run threat modeling for new features with product and engineering teams
- Write and maintain the application security controls for FedRAMP continuous monitoring
- Lead the security champions program across 20 engineering teams
- Support incident response when an application vulnerability is exploited or reported

## What we are looking for

### Required

- Eight or more years in security, at least five in application security
- OSCP, OSWE, or an equivalent offensive security certification
- Extensive hands-on penetration testing of web applications with Burp Suite
- Experience building fuzzing into CI for compiled languages
- Strong code reading skills in Java and at least one of Rust, Go, or C++
- Experience with FedRAMP, StateRAMP, or a comparable government authorization
- Ability to obtain a federal public trust clearance

### Preferred

- Experience writing custom Semgrep rules
- Python or Go for security tooling
- Cloud security experience on AWS
- Experience presenting to government customers and auditors

## How we work

- Product security engineers are embedded with two or three product teams each
- Findings come with a fix or a pull request whenever possible
- We publish an internal security newsletter every month

## Benefits

- Comprehensive health coverage and a 6% retirement match
- Four weeks of paid time off
- Annual training budget, including offensive security courses and exams

## Interview process

1. Hiring manager conversation
2. A live code review exercise in Java
3. A web application penetration testing exercise
4. A threat modeling session with an engineering lead
