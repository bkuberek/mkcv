# Senior Cloud Security Engineer

**Company:** Kelvara Systems
**Team:** Security Engineering
**Location:** Remote (US) or hybrid in Kestrel Bay, WA
**Employment type:** Full time
**Base salary:** $175,000 to $205,000, plus equity

## About Kelvara Systems

Kelvara Systems makes payroll and benefits software for 9,000 mid-size
employers. We hold sensitive data for more than two million workers, so
security is part of the product. Everything we run is on AWS, across about 80
accounts, and our engineers deploy many times a day.

## About the role

You will join a security engineering team of eight and own big parts of our
cloud security posture and our detection and response program. We want
someone who writes code, prefers guardrails to gates, and can lead an
incident at 2 a.m. and the postmortem the next day.

## What you will do

- Harden AWS IAM across the organization: least-privilege roles, permission boundaries, and removing long-lived credentials
- Build and maintain security guardrails in Terraform, including SCPs and policy-as-code checks in CI
- Lead detection engineering: write, test, and tune detections as code for our SIEM
- Serve as an incident commander for security incidents and improve incident response playbooks
- Run threat modeling with product teams for new services and major changes
- Automate security workflows in Python
- Support SOC 2 and PCI DSS audits with evidence and control improvements
- Mentor engineers and grow our security champions program

## What we are looking for

### Required

- Six or more years in security engineering, with at least three focused on AWS
- Deep knowledge of AWS IAM, Organizations, CloudTrail, GuardDuty, and Security Hub
- Experience writing infrastructure as code in Terraform
- Strong Python skills
- Hands-on detection engineering experience with Splunk, Sigma, or a similar SIEM
- Experience leading incident response for cloud incidents
- Experience with compliance frameworks such as SOC 2 or PCI DSS

### Preferred

- Kubernetes security experience, especially on EKS
- Experience in fintech, payroll, or another regulated industry
- CISSP or an AWS security certification
- Experience running tabletop exercises

## How we work

- Security engineers write code and ship changes through the same pipelines as everyone else
- Every incident gets a blameless postmortem with owners and dates
- We measure ourselves by how few tickets we need to send to other teams
